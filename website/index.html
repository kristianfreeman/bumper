Questions.

Do I need a Jellyfin server?

Yes. Bumper plays what's on a Jellyfin server — yours, or one a friend or family member shares with you. It isn't affiliated with the Jellyfin project.

What does it cost?

Bumper is free. Some of its 62 themes are an optional purchase; everything else is included.

Which devices does it run on?

Apple TV, iPhone, iPad and Mac, on tvOS 26, iOS 26, iPadOS 26 and macOS 26 or later. That includes the first Apple TV 4K, from 2017.

Does it work away from home?

Yes, if your server can be reached over the internet. Bumper keeps a few seconds of the film ready when it's streaming from far away, so a patchy connection doesn't cut the sound.

Will it play my files?

Almost certainly — see the compatibility table above. Bumper plays files as they are, so your server doesn't need to convert them (or be powerful enough to).

What does Bumper know about me?

Nothing it sends anywhere. There are no accounts, no ads and no analytics. The privacy page lists exactly what goes where.

How do I try it?

Install TestFlight from the App Store, then open the beta link on your Apple TV, iPhone, iPad or Mac.
